# Contributing

Vibe GitTree is a personal project. It's public so you can read it, clone it, build it and fork it, but
it isn't open to contributions.

- **Issues are welcome**: bug reports, questions and ideas. For a bug, say what you did, what you
  expected and what happened, with your macOS version and how you built or installed Vibe GitTree.
- **Pull requests aren't accepted.** Please don't open one; if you'd like a change, open an issue
  describing it, or make it in your own fork.
- **Forks are welcome**: change anything you like in yours, under the [MIT license](LICENSE).
